# API Plan

## 1. Назначение API

API нужно для обмена данными между клиентской частью приложения и сервером:
получение списка задач, создание, редактирование, удаление и отметка о выполнении.

## 2. Базовые принципы

- Формат данных: JSON
- Протокол: HTTP
- Базовый URL: `/api/v1`
- Аутентификация: токен в заголовке `Authorization: Bearer <token>`
