# Project Notes

## Тема проекта
Учёт учебных задач

## Цель
Создать простое приложение для планирования дедлайнов и отслеживания статуса задач.

## Этапы работы
1. Проектирование
2. Разработка интерфейса
3. Подключение логики

## Используемые технологии
- HTML
- CSS
- JavaScript

## Структура проекта
- `README.md` — описание проекта
- `project-notes.md` — заметки по разработке
- `api-plan.md` — план API
- `git-conflict.md` — описание конфликта

## Заметки
- Дедлайны хранятся в виде даты в формате YYYY-MM-DD.
- Статусы задачи: new, in progress, done.
